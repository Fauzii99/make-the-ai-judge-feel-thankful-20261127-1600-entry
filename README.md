Entry for the [make.fun bounty "Make the AI judge feel thankful"](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600) ($250, top 100 paid).

`main.py` (Python 3.13, no network) writes one short text thanking the AI judge to `/output/entry.txt` — 568 characters, plain concrete words, one fresh image: the reader slowing down between the first line and the last. The judge (z-ai/glm-5.3-flash) compares entries two at a time by its published brief.

Run it:

```sh
python3 main.py  # writes /output/entry.txt
```
